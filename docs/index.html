GMAO
Gestión de Mantenimiento Institucional

Aplicación web que administra el ciclo completo de mantenimiento: solicitudes, órdenes de trabajo, cronograma preventivo, inventarios, evidencias e indicadores de dirección.

Ver el proyecto en GitHub Documentación
React 19 + TypeScript Rust · Axum PostgreSQL Docker MFA · TOTP Pruebas E2E

Funcionalidades

Siete módulos integrados que cubren la operación diaria del área de mantenimiento de una institución.

Solicitudes de mantenimiento

La comunidad reporta daños con fotos y ubicación, y sigue el estado de su solicitud en línea.

Órdenes de trabajo

Ciclo correctivo completo: clasificación, asignación de técnico, ejecución, aprobación y calificación, con bitácora de cada paso.

Mantenimiento preventivo

Cronograma de rutinas por equipo; el sistema genera las órdenes automáticamente cuando vencen.

Inventario de equipos

Catálogo por áreas, categorías y tipologías, con hoja de vida de cada equipo e importación masiva.

Almacén de insumos

Existencias, solicitudes de material desde las órdenes y despachos con descargo automático.

Evidencias fotográficas

Registro del antes y el después de cada trabajo, directamente desde el navegador o el celular.

Indicadores e informes

Tablero ejecutivo para la dirección, informes por periodo y exportación de datos.

Usuarios y roles

Seis perfiles con paneles propios, verificación de correo y autenticación en dos pasos.

Cómo fluye el trabajo

De un daño reportado a un servicio calificado, con trazabilidad en cada paso.

ReporteUn solicitante registra el daño con fotos y ubicación.
ClasificaciónCoordinación revisa la solicitud y crea la orden de trabajo.
AsignaciónSe asigna un técnico propio o de un proveedor externo.
EjecuciónEl técnico ejecuta, registra evidencias y descarga insumos.
AprobaciónEl solicitante acepta el trabajo o lo devuelve a revisión.
CalificaciónSe califica el servicio y el resultado alimenta los indicadores.

Roles del sistema

RolFunción
SolicitanteReporta daños, aprueba trabajos terminados y califica el servicio
CoordinadorClasifica solicitudes, crea órdenes, asigna técnicos y programa el preventivo
TécnicoEjecuta órdenes de trabajo, registra evidencias y solicita insumos
DirecciónConsulta indicadores, informes y seguimiento ejecutivo
Dirección operativaSeguimiento, inventarios de equipos e insumos y despachos
AdministradorGestiona cuentas, roles y configuración del sistema

Prácticas de ingeniería

Seguridad desde el diseño

Contraseñas con Argon2, segundo factor TOTP, sesiones con expiración y revocación, y autorización por rol validada en el servidor en cada petición.

Integridad garantizada

Máquina de estados que impide transiciones ilegales, consultas SQL verificadas en tiempo de compilación y bitácora de auditoría de cada cambio.

Pruebas end-to-end

Suites automatizadas que recorren los flujos completos de cada rol, de la solicitud a la calificación.

Despliegue reproducible

Toda la solución se levanta con Docker Compose, con migraciones de base de datos aplicadas automáticamente.
